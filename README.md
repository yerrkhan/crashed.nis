# crashed.nis

Копия [исходного проекта arsendgaf/crashed.nis](https://github.com/arsendgaf/crashed.nis) с калькулятором четвертной оценки для учеников НИШ.

## Калькулятор

Откройте предмет в журнале и нажмите **«Рассчитать оценку»**. Можно менять набранные и максимальные баллы СОР и СОЧ, добавлять будущие работы и сразу видеть прогноз процента и оценки. Кнопка **«Сбросить»** возвращает значения из журнала. Расчёт работает только в браузере и не меняет школьные данные.

Формула: `СОР / максимум СОР × 50% + СОЧ / максимум СОЧ × 50%`. Оценка: ниже 40% — «2», 40–64% — «3», 65–84% — «4», от 85% — «5». Пока не введены баллы всех работ, итоговая оценка не показывается. Шкала и веса взяты из [правил НИШ](https://www.nis.edu.kz/storage/files/01JRJ440AQ156MK94BAV50D8CX.pdf).

## Локальный запуск

Требуются Node.js и pnpm 8. Скопируйте `.env.example` в `.env.local`, при необходимости измените публичные ссылки, затем выполните:

```sh
pnpm install
pnpm dev
```

Сайт использует авторизацию и данные НИШ, поэтому для просмотра журнала нужен действующий школьный аккаунт.
